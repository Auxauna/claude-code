# Keystone Intel

AI-powered intelligence infrastructure for elite real estate brokers.

**We do the research. You close the deals.**

## Services

- **CompIQ Reports** - Comprehensive market analysis with AI-curated comps
- **DealScan** - Property due diligence and risk analysis
- **MarketPulse** - Real-time market alerts and weekly digests
- **ListingForge** - Marketing content and listing descriptions
- **InvestorBrief** - Investment property cash flow analysis

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Deploy to Vercel with one click - the project is configured for automatic deployment.

## Tech Stack

- Next.js 16
- Tailwind CSS v4
- shadcn/ui components
- TypeScript
